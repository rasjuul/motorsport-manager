# Motorsport Manager

I am building a Formula 1-inspired motorsport management game in C# with fictional teams and drivers. This is my personal learning project.

I want to improve my understanding of C# by building a game with meaningful decisions and a manageable scope. I am still learning, so I will build it step by step and keep the code understandable.

## Current status

The repository and project rules are being set up. There is no playable game yet.

## My first playable version

- A console application with a six-race season.
- Four fictional teams with two drivers each.
- Management of both drivers in my team.
- A few driver attributes and a simple car strength rating.
- Simple qualifying, race pace, tyre wear and pit-stop decisions.
- Race results, driver standings and team standings.
- Saving and loading a season.

I will start with a working race simulation, add player decisions, and then build the season and save system. Weather, contracts, finances, car development, graphics and multiplayer are outside the initial scope.

I keep project files, documentation and commit messages in English. I document completed changes and record what has actually been tested. At pauses and at the end of a working day, I create a hand-off and back up the project to my private backup location.
